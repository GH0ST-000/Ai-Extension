# @project-x/ui

Shared UI primitives based on shadcn/ui patterns.

## Included

- `Button`
- `Input`
- `Card` (+ header/title/description/content)
- `cn` utility

## Usage

```tsx
import { Button, Card, Input } from '@project-x/ui';
```

Import shared styles from the dashboard (or other Tailwind apps):

```ts
import '@project-x/ui/globals.css';
```
